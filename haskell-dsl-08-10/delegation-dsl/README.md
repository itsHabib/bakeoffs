# Delegation DSL

An artifact-first language for multi-agent handoffs. One contract validates
producer uniqueness, compiles dependency batches, and emits a local brief for
each role describing exactly what it receives and delivers.

```powershell
stack test
stack run
```

The strongest alternative is a small TypeScript graph validator over a manifest.
This candidate earns Haskell points only if its compositional authoring and
projection stay clearer as contracts gain real alternatives; the bounded POC
deliberately exposes the risk that it is merely a pleasant dependency list.
