# Assurance DSL

One evidence-policy value supports requirement discovery, exact-revision
evaluation, and structured explanation. Stale evidence is a first-class failure,
and alternative authorization paths retain which evidence succeeded.

```powershell
stack test
stack run
```

The strongest ordinary alternative is a TypeScript policy AST. Haskell's closed
algebra makes exhaustive interpreters and compositional authoring unusually
small, but this candidate loses if the explanation tree is not useful enough to
justify a purpose-built DSL.
