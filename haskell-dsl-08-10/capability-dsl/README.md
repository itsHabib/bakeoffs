# Capability DSL

A free-applicative agent plan that returns heterogeneous typed results while
retaining its complete operation tree. The same value renders a dry run,
computes an exact authority envelope, and executes only after full preflight.

```powershell
stack test
stack run
```

A Rust command enum is the strongest conventional alternative and is simpler
for untyped batches. The Haskell advantage is typed result composition; the
cost is that result-dependent future operations cannot remain statically
visible.
