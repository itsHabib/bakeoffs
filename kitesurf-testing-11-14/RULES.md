# Build constraints

Build three independent, small tools around testing, mocking and browser-driven diagnosis. Each entry chooses a distinct useful job and exports an inspectable artifact.

- One independent build context per entry; no shared product code.
- Real Kitesurf executes the meaningful browser work. No silent engine fallback.
- Correctness is deterministic code, with tests and deliberately broken controls.
- Two synthetic workloads per tool and a documented input interface.
- A hands-free demo, README, 60-second walkthrough and honest limits.
- No accounts, cloud deployment, paid APIs or production data.
- Compare honestly with a plain script or existing browser/mocking tool. No unsupported novelty or performance claims.

Human judging: demo 30, usefulness 25, deterministic correctness 20, meaningful Kitesurf use 15, restraint 10. No winner selected.
